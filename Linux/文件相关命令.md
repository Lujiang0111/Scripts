# 文件相关命令

## 查找当前目录及子目录的可执行文件

```shell
find ./ -type f -perm /111 -print
```

其中
+ `-type f`：只查找普通文件。
+ `-perm /111`：文件的所有者、所属组、其他用户中，任意一类具有执行权限即可匹配。

## 生成大文件

1. fallocate（快速生成大文件）

    ```shell
    fallocate -l 1G test.bin
    ```

1. dd（测试写入速度）

    ```shell
    # 创建 1GB 随机数据文件
    dd if=/dev/urandom of=random.bin bs=1M count=1024 status=progress

    # 创建 1GB 全零文件
    dd if=/dev/zero of=test.bin bs=1M count=1024 status=progress
    ```
